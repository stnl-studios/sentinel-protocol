- unauthorized promotion/runtime/materialization/production drift scan;

## Section Anchors

The anchor matrix validates required positive anchors in their owner
file/section. It does not satisfy an anchor by searching every path, and it
does not use a `paths.some(...)` substitute for mandatory anchors.

Positive anchors must be local affirmative claims. Prohibitive anchors must be
local prohibitive claims. A distant negation in the same block does not protect
a positive drift claim. Contradiction local fails the harness.

Required status anchors include `VALIDATION_RUNNER_KERNEL:
CLEAN_EXCELLENT_PASS`, documentary promotion applied, documentary validation
pass, contractual pass, minimum semantic pass, hardened textual executable
harness pass, `dev kernel lab only`, `non-runtime`, `non-production`,
`no materialization path`, `no runtime loader`, `no materializer`, `no target
artifact`, `no productive skill activation`, `no template mutation`, harness
textual exists, and harness pass does not authorize status extension outside
the dev kernel lab.
