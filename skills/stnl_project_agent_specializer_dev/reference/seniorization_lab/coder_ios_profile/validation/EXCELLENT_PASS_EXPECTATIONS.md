  artifact without creating validation verdict, semantic review, closure, or

  decisions are resolved upstream or blocked rather than exported downstream.

## Evidence Discipline Excellence

- The profile distinguishes applied implementation from intention, command run
  from command suggested, command not run from command passed, local check from
  formal validation, executor evidence from runner verdict, reviewer decision,
  and finalizer closure.
- `READY` requires changed paths or equivalent implementation evidence.
- Skipped, unavailable, blocked, or failed checks are reported honestly.
- Partial edits without safe completion force explicit `BLOCKED` handling with
  touched files, remaining partiality, objective blocker, and reuse/discard
  guidance.
- "Should compile", absence of visible error, code edit, or local inspection
  confidence never becomes validation `PASS`.
