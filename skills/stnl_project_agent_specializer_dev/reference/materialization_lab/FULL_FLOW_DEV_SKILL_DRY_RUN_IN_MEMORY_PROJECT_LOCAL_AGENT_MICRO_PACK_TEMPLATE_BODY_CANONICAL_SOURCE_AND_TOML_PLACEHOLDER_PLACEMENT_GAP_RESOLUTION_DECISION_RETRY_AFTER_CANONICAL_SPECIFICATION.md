## 37. Format safety and escaping resolution

- Encoding is UTF-8 without BOM; newline is LF.
- CR, NUL, disallowed C0 controls, trailing spaces, and trailing tabs are rejected; TAB is allowed only where the specification permits and is escaped in TOML strings.
- Markdown doubles backslashes and escapes backtick, `*`, `_`, `[`, `]`, `<`, `>`, and `|`; structural line-start markers and the dot in a numeric-list prefix are escaped when they arise from a value.
- TOML single-line basic strings double backslashes, escape double quotes, and encode TAB as `\t`; remaining controls abort.
- TOML multiline basic strings are allowed only for `developer_instructions`; its six LF separators are structural, not placeholder-provided.
- Quote, backslash, newline, and comment-like content are handled by the destination format, never by raw unsafe interpolation.
- Nested placeholders, multiline identifiers, and placeholder-provided newlines are forbidden.

No renderer, parser, schema, or validator is created by this resolution.
