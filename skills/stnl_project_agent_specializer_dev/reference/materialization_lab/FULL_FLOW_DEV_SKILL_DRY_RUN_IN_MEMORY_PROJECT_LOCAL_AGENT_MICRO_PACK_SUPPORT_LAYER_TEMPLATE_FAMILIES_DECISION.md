The inherited architecture remains:

`PROJECT_LOCAL_AGENT_MICRO_PACK_MATRIX`

to copy kernels, Senior Agent Profiles, or `/docs` wholesale into target
entrypoints or support packs.

Preserved baseline:

- `.github/agents/<agent>.agent.md` remains the GitHub entrypoint shape;
- `.codex/agents/<agent>.toml` remains the Codex entrypoint shape;
- entrypoints stay small;

- `.sentinel/agents/<agent>/**` is the per-agent project-local micro-pack;
- shards are classified as `always`, `hot`, `warm`, `cold`, and `trace`;
- `START.md` is the minimal entry;
- `MANIFEST.md` controls activation;
- `_shared` centralizes common rules;
- kernels and Senior Agent Profiles are strong sources but not literal
  payloads;
- `/docs` is consumed on demand and is not dumped;
- behavior parity comes through traceability;
- the skill remains immutable per project.
