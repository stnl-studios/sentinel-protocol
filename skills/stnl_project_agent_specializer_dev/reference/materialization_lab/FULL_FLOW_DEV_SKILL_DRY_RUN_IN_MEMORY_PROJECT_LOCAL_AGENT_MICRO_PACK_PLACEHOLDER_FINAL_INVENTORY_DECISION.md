## 18. Placeholder inventory decision model

Each inventory row records a canonical name, logical namespace, conceptual
owner, conceptual scope, purpose, value status, Target dependency, allowed

is not machine-readable authority, an executable contract or a template.

`derived-documentary`, `future-target-dependent` and `forbidden`. No row below
contains a value.

`platform` and `target`. They separate shared support rules, per-agent support,

`derived-documentary` classify future provenance, not populated content.
