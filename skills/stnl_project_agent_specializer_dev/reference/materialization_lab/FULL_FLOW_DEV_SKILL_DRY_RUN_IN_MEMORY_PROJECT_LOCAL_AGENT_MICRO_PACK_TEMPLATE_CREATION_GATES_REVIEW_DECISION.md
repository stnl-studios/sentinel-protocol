## 7. Inherited baseline

The inherited architecture remains:

`PROJECT_LOCAL_AGENT_MICRO_PACK_MATRIX`

The architecture is for light agent materialization planning, not heavy agent
generation. It preserves small platform entrypoints, project-local support
micro-packs, temperature-based shards, controlled activation, non-copy
transformation from strong sources, on-demand `/docs` consumption, traceable
behavior parity, and skill immutability per project.

Preserved baseline:

- entrypoints stay small;
- `.github/agents/<agent>.agent.md` remains the GitHub entrypoint shape;
- `.codex/agents/<agent>.toml` remains the Codex agent entrypoint shape;
- `.sentinel/agents/_shared/**` is the shared project-local support layer;
- `.sentinel/agents/<agent>/**` is the per-agent project-local micro-pack;
- shards are classified as `always`, `hot`, `warm`, `cold`, and `trace`;
- `START.md` is the minimal entry;
- `MANIFEST.md` controls activation;
- `_shared` centralizes common rules;
- kernels and Senior Agent Profiles are strong sources but not literal payloads;
- `/docs` is consumed on demand and is not dumped;
- `trace` is audit-only by default;
- behavior parity comes through traceability;
- the skill remains immutable per project.
