## 14. Qualitative anti-bloat criteria

The following criteria are normative:

- entrypoints must be small and point to local activation;
- `START.md` must stay minimal and must not become a full instruction body;
- `MANIFEST.md` must control activation and must not copy shard content;
- `_shared` must centralize common rules;
- common rules must not be duplicated per agent;
- per-agent shards must be specific to the owning agent;
- `hot`, `warm`, and `cold` shards must depend on activation triggers;
- `trace` must remain audit-only;
- trace must not become a mirror of sources;
- kernels are strong sources, not payloads for literal copy;
- Senior Agent Profiles are strong sources, not payloads for literal copy;
- `/docs` must be consumed on demand and never dumped wholesale;
- the support layer must not become a third matrix of agents;
- behavior parity must be traceable by summaries, anchors, and transformation
  notes, not by literal copy.
